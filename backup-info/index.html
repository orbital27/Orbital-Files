Purdue Orbital Backups

An administrator-operated tool for protecting Purdue Orbital's website information.

What it does

The backup runner exports the website database, uploaded files, and website source code. It encrypts each archive before uploading it to the administrator's designated Google Drive backup folder, then downloads the archive to verify its checksum.

Why it connects to Google Drive

The administrator authorizes Drive access so the runner can check available storage, create backup files, and read those files for verification and recovery. Club members do not need to connect their Google accounts.

Access and recovery

This is a club administration tool, not a public backup service. Backups are encrypted; an independently retained recovery key is required to open them. Successful upload verification is separate from testing a database restore.

Backup privacy policy

This policy covers the Purdue Orbital Backups administration tool.

Data accessed and purpose

The tool uses Google OAuth credentials, Drive storage-quota information, and file and folder metadata to upload, locate, and verify encrypted backups in the designated backup folder. It downloads backup archives for verification or authorized recovery.

The current Google authorization grants full Drive access. The configured folder is a restriction in the backup runner, not a Google-enforced boundary on that authorization. The runner is configured to operate on the designated backup folder and does not intentionally read unrelated Drive documents.

Backup contents and processing

Archives can contain club member account records, project and personal pages, task assignments, uploaded images and documents, database permissions, and website source code. Supabase supplies the website data. GitHub Actions processes it temporarily to create the encrypted archive. Google Drive stores the encrypted archives and completion receipts. Administrators with the recovery key can decrypt backup contents.

Credential protection and sharing

Automation credentials are stored as encrypted GitHub Actions secrets. Authorized repository maintainers can change workflows that use them. Setup and recovery may also use credentials on the administrator's computer. The recovery key is kept separately from the automated runner. Backup data is used for backup, verification, and recovery, not sold or used for advertising or model training.

Retention and deletion

The current runner does not automatically delete old backups. It stops uploading when its configured storage budget would be exceeded. Removing information from the live website does not remove it from older backup archives. The administrator manages archive retention and deletion in Drive, including any copies retained for recovery.

Control and contact

The Google account owner can revoke the app's access in Google Account third-party connections. Revoking access stops future authorized operations; it does not delete existing archives. Contact purdueorbital27@gmail.com for questions about access or deletion.
